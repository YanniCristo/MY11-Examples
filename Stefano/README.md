# Cartella Stefano

- **REGOLE_MY11.md** – regole per creare i file .my11 (titoli, loghi, posizioni, riserve, voti, grandezze, banner). Si aggiorna ogni volta che aggiungiamo o affiniamo una regola.
- **Maglie Serie A/** – le 20 maglie MY11 delle squadre di Serie A, con il nome della squadra.
- **Copia file Fulvio (con possibili modifiche)/** – COPIA dei file originali di Fulvio (Moduli, Loghi, Pics, Stadi, Maglie). Qui si fanno aggiunte e miglioramenti; gli originali nelle cartelle principali del repository restano intatti.
- **Lineups/** – cartelle formazioni pronte: `SERIE A.my11` (20 squadre, ordine alfabetico, anteprime con base stadio) e `NBA Lineups.my11` (30 quintetti NBA, anteprime con campo da basket).
- Nella copia di Fulvio sono stati aggiunti: `Pics/NBA.my11` (30 canotte NBA), `Maglie/NBA/` (canotte PNG), `Stadi/Basket.jpg` (campo da basket), `Loghi/NBA Logos.my11` e i file loghi delle leghe e coppe.
