# Modelli di riferimento

File di prova già verificati nell'app, da usare come base quando si crea un nuovo file.

| File | Tipo | Cosa mostra |
|---|---|---|

Immagini in `images/sub_N/`, 300×320, base a filo, spazio trasparente in alto, label solo cognome maiuscolo. Per una cartella senza sottocartelle: stesse immagini in `images/` e `"subfolders":[]`. |
