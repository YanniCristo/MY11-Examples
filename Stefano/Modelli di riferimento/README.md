# Modelli di riferimento

File di prova già verificati nell'app, da usare come base quando si crea un nuovo file.

| File | Tipo | Cosa mostra |
|---|---|---|
| `Riferimento_cartella_immagini.my11` | Cartella immagini (`my11-pics-folder` v2) | Logo squadra in testa (label = nome squadra) + 3 giocatori a 300×320, base a filo, spazio trasparente in alto, label solo cognome maiuscolo |
